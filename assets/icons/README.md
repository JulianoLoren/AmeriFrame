# Mosaic app icon

The original geometric collage mark is defined in `generate.py`: warm gold, sage and clay cells on charcoal, separated by an ivory frame. No external artwork or fonts are used.

Run `python3 assets/icons/generate.py` from the repository to regenerate the SVG/favicon, Apple touch icon, opaque 1024 px iOS icon, Android adaptive/themed vectors, multi-resolution macOS ICNS and Windows ICO. Python's standard library is sufficient. Commit the generated files together with source changes.
